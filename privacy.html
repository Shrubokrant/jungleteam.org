Privacy Policy

Last updated: July 4, 2026

Jungle (jungleteam.org) is a one-person studio run by William "Shru" Besnard. This page explains what data this website collects and how it's used. This is a small indie project — the short version is: this site doesn't run ad trackers or sell your data, and there's no user account system.

1. What this site collects

  • Server logs: standard web server logs (IP address, browser user-agent, requested page, timestamp) are kept for basic security and debugging, and rotated periodically.
  • Fonts: this site loads Google Fonts (Baloo 2, Lato) from Google's CDN, which may log the request (IP, browser) per Google's own privacy policy.
  • No cookies, no analytics, no ad tracking are set by this site itself at this time.

2. Plugin purchases

Jungle plugins are sold through the Unity Asset Store. Payment processing and any account data involved in a purchase is handled entirely by Unity — see Unity's Privacy Policy. Jungle does not receive your payment details.

3. Third-party / social platforms

Links on this site lead to third-party platforms — Discord, Bluesky, Mastodon, X, LinkedIn, YouTube, TikTok, GitHub. Any data you share there (messages, follows, comments) is governed by that platform's own privacy policy, not this one.

4. Your rights (EU / GDPR)

Since this site collects only minimal server-log data and no account data, there's little to request — but if you'd like your IP removed from logs or have any privacy question, contact me and I'll handle it directly.

5. Changes

This policy may be updated as Jungle adds services (e.g. a mailing list). Material changes will be reflected by the "Last updated" date above.

6. Contact

Questions about this policy: reach out on Discord or via the contact details on the About page.
